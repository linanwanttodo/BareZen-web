接口文档也是同一份声明

GET /api/document 由 OpenApiPlugin 的声明数据生成（ADR-0043）。它只描述返回 JSON 的端点： ApiResponse 能说"有一个 JSON body"或"没有 body"，说不了 HTML 页面，所以这个页面自己不在文档里 —— 这是被点名的模型边界，不是遗漏。

这个页面在证明什么。框架的公开面够用：路由、会话、装饰器式的安全、插件扩展点、静态文件、数据访问， 一个应用只用公开 API 就能把它们串起来（编译期就保证了这一点，因为它是一个独立 Maven 模块）。 它没有证明什么。认证用的是 Authorization: Bearer，不是 cookie —— 因为 SecurityMiddleware 只从 Authorization 取凭证，框架没有第二种 credential source； 所以刷新页面会掉登录，token 只存在内存里（放进 localStorage 等于把它交给任何能在这页执行的脚本）。 需要 cookie 会话时，那条扩展点得先按规矩开一份 ADR，而不是在这里绕过。
