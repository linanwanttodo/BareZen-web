API 参考

九个 BareZen 模块中所有公共类和接口的完整索引。

barezen-core

基础：生命周期、配置、DI、事件、线程。

com.barezen.core.kernel

类型描述
LifecycleOrchestrator驱动注册参与者的启动、关闭和回滚。Builder API：register()、threadPolicy()、registerShutdownHook()。
LifecycleParticipant接口：initialize()、start()、stop()、abort()。所有方法都有空默认实现。
ApplicationState枚举：NEW、STARTING、RUNNING、STOPPING、STOPPED、FAILED。

com.barezen.core.config

类型描述
Configuration只读配置快照。工厂：standard(Path)、inMemory(Map)、of(ConfigurationSource...)。
ConfigurationKey<T>带可选默认值的类型安全键。ConfigurationKey.of(name, type, default)。
ConfigurationSource配置源接口。实现：PropertiesConfigurationSource、EnvironmentVariablesSource、SystemPropertiesSource。

com.barezen.core.di

类型描述
ServiceAssembly显式 DI 容器。Builder：instance(Class, T)、factory(Class, Function)。解析：require(Class)、find(Class)。
Services工厂在组装期间接收的视图。require(Class) 和 find(Class)。

com.barezen.core.event

类型描述
EventBus同步进程内发布/订阅。create()、subscribe(Class, EventHandler)、publish(T)。
Subscription订阅返回的句柄。cancel() 取消订阅。

com.barezen.core.concurrent

类型描述
ThreadProvider创建执行器。newBoundedExecutor(int, String)、newUnboundedExecutor(String)、close()。
ThreadProviders工厂：create(ThreadPolicy, RuntimeCapabilities)。
ThreadPolicy枚举：AUTO、PLATFORM、VIRTUAL。
RuntimeCapabilities检测虚拟线程支持。detect()。

com.barezen.core.plugin

类型描述
Plugin扩展 LifecycleParticipant 的接口。descriptor() 返回 PluginDescriptor。
PluginDescriptor记录：name、version、description。
PluginDiscovery通过 ServiceLoader 发现插件。

barezen-web

HTTP 契约：Request、Response、Router、Handler。

类型描述
Handler函数式接口：Response handle(Request, Map<String, String>)。
Request不可变记录：method、path、query（Optional）、headers、body（byte[]）。
Response不可变：status（int）、headers、body（byte[]）。强制：1xx/204/304 无主体，无 Content-Length。
Headers多值头部集合。of()、with()、first()、values()、names()。
HttpMethod类（非枚举）：GET、HEAD、POST、PUT、DELETE、PATCH、OPTIONS、CONNECT、TRACE。of(String) 用于自定义方法。
Router不可变路由表。Builder：route(method, pattern, handler)、contributing(List<RouteContributor>)。查询：match(Request)、methodsFor(String)。
RouteMatch记录：handler、parameters（Map<String, String>）。
RouteContributor接口：contributeRoutes(Router.Builder)。
HttpServerAdapter扩展 LifecycleParticipant 的接口：port() 返回 OptionalInt。

barezen-http-jdk

带虚拟线程和 TLS 的 JDK HttpServer 适配器。

类型描述
JdkHttpServerAdapter构造函数：(address, router)、(address, router, ThreadProvider)、(address, router, Configuration)。方法：start()、stop()、isRunning()、port()。

配置键

键类型默认值
barezen.http.jdk.maxRequestBodyBytesLong1 MB
barezen.http.jdk.tls.keystorePathString无（明文）
barezen.http.jdk.tls.keystorePasswordString如果设置了 keystorePath 则必需

barezen-http-servlet

Servlet 容器集成。

类型描述
BarezenServlet扩展 HttpServlet。构造函数：()（声明式）、(Router)（编程式）。常量：ROUTER_ATTRIBUTE、MAX_REQUEST_BODY_BYTES_PARAM。

barezen-security

认证、授权、会话、密码哈希。

类型描述
Authentication函数式接口：AuthenticationResult authenticate(Credential)。工厂：anonymous()、bearer(scheme, value, principal)。
AuthenticationResult密封接口。子类型：Authenticated(Principal)、Failure(String)、Anonymous。工厂：authenticated()、failure()、anonymous()。
Authorization函数式接口：Decision authorize(Principal, Permission)。工厂：allowAll()、denyAll()、of(Map<Principal, Set<Permission>>)。
Principal记录：name（String）。工厂：Principal.of(String)。
Permission不可变字符串标识符。工厂：Permission.of(String)。
Credential记录：scheme（String）、value（String）。
SecurityContext记录：authentication（AuthenticationResult）。方法：principal()、isAuthenticated()。
SecuredHandler用安全包装处理程序。authenticated(Handler)、require(Handler, Permission)。
SecurityMiddleware将认证和授权连接到管道。create(Authentication, Authorization)。
SessionStore内存会话存储。standard()、create(Principal, Duration)、lookup(String)、invalidate(String)、rotate(String, Duration)。
SessionToken32 字节随机令牌。value()、isExpired(Instant)。
PasswordHasherPBKDF2-HMAC-SHA256。standard()、of(iterations, SecureRandom)、hash(String)、verify(String, String)。

barezen-data

数据库访问、事务、迁移。

类型描述
Database入口点。构造函数：(DataSource)。方法：query(sql, RowMapper, params)、executeUpdate(sql, params)、transaction(TransactionCallback)。
Transaction事务作用域访问。方法：query()、executeUpdate()、queryForLong()。
RowMapper<T>函数式接口：T map(ResultSet, int)。
Migration接口：version()、description()、apply(Connection)。
Migrator应用迁移。构造函数：(Database)。方法：migrate(List<Migration>)。
DataAccessException包装 SQLException 的运行时异常。

barezen-content

静态文件服务。

类型描述
StaticContent静态工具。file(Path) 推断内容类型。file(Path, String) 带显式类型。resource(ClassLoader, String) 及显式类型重载提供冻结的类路径资产。contentTypeOf(String) 将扩展名映射到 MIME 类型。Handler 提供 ETag、条件 GET（仅 GET/HEAD）、GET 上的单字节范围（206/416）。

barezen-testkit

集成测试工具。

类型描述
TestServer随机端口上的真实 HTTP 服务器。start(Router)、port()、baseUri()、client()、isRunning()、close()。
TestHttpClientTestServer 的 HTTP 客户端。方法：get()、head()、post()、put()、patch()、delete()、options()、request(method, path)。
TestResponse响应：status()、header(String)、body()、bodyBytes()。
Assertions流式断言。assertThat(TestResponse)、assertThat(int)、assertThat(Optional<Principal>)。
TestDatabase内存 H2 数据库。create()、database()、dataSource()、close()。

barezen-plugins

内置插件。

类型描述
AuthPlugin认证插件。贡献 /auth 路由。
UserPlugin用户管理插件。贡献 /users 路由。
OpenApiPluginOpenAPI 文档插件。贡献 /openapi.json 路由。

异常模块何时
