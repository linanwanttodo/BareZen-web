API reference

Complete index of all public classes and interfaces across the nine BareZen modules.

barezen-core

Foundation: lifecycle, configuration, DI, events, threading.

com.barezen.core.kernel

TypeDescription
LifecycleOrchestratorDrives startup, shutdown, and rollback for registered participants. Builder API: register(), threadPolicy(), registerShutdownHook().
LifecycleParticipantInterface with initialize(), start(), stop(), abort(). All have empty defaults.
ApplicationStateEnum: NEW, STARTING, RUNNING, STOPPING, STOPPED, FAILED.

com.barezen.core.config

TypeDescription
ConfigurationRead-only configuration snapshot. Factories: standard(Path), inMemory(Map), of(ConfigurationSource...).
ConfigurationKey<T>Type-safe key with optional default. ConfigurationKey.of(name, type, default).
ConfigurationSourceInterface for configuration sources. Implementations: PropertiesConfigurationSource, EnvironmentVariablesSource, SystemPropertiesSource.

com.barezen.core.di

TypeDescription
ServiceAssemblyExplicit DI container. Builder: instance(Class, T), factory(Class, Function). Resolution: require(Class), find(Class).
ServicesView a factory receives during assembly. require(Class) and find(Class).

com.barezen.core.event

TypeDescription
EventBusSynchronous in-process pub/sub. create(), subscribe(Class, EventHandler), publish(T).
SubscriptionHandle returned by subscribe. cancel() to unsubscribe.

com.barezen.core.concurrent

TypeDescription
ThreadProviderCreates executors. newBoundedExecutor(int, String), newUnboundedExecutor(String), close().
ThreadProvidersFactory: create(ThreadPolicy, RuntimeCapabilities).
ThreadPolicyEnum: AUTO, PLATFORM, VIRTUAL.
RuntimeCapabilitiesDetects virtual thread support. detect().

com.barezen.core.plugin

TypeDescription
PluginInterface extending LifecycleParticipant. descriptor() returns PluginDescriptor.
PluginDescriptorRecord: name, version, description.
PluginDiscoveryDiscovers plugins via ServiceLoader.

barezen-web

HTTP contract: Request, Response, Router, Handler.

TypeDescription
HandlerFunctional interface: Response handle(Request, Map<String, String>).
RequestImmutable record: method, path, query (Optional), headers, body (byte[]).
ResponseImmutable: status (int), headers, body (byte[]). Enforces: no body for 1xx/204/304, no Content-Length.
HeadersMulti-value header collection. of(), with(), first(), values(), names().
HttpMethodClass (not enum): GET, HEAD, POST, PUT, DELETE, PATCH, OPTIONS, CONNECT, TRACE. of(String) for custom methods.
RouterImmutable route table. Builder: route(method, pattern, handler), contributing(List<RouteContributor>). Query: match(Request), methodsFor(String).
RouteMatchRecord: handler, parameters (Map<String, String>).
RouteContributorInterface: contributeRoutes(Router.Builder).
HttpServerAdapterInterface extending LifecycleParticipant: port() returns OptionalInt.

barezen-http-jdk

JDK HttpServer adapter with virtual threads and TLS.

TypeDescription
JdkHttpServerAdapterConstructors: (address, router), (address, router, ThreadProvider), (address, router, Configuration). Methods: start(), stop(), isRunning(), port().

Configuration keys

KeyTypeDefault
barezen.http.jdk.maxRequestBodyBytesLong1 MB
barezen.http.jdk.tls.keystorePathStringNone (plaintext)
barezen.http.jdk.tls.keystorePasswordStringRequired if keystorePath set

barezen-http-servlet

Servlet container integration.

TypeDescription
BarezenServletExtends HttpServlet. Constructors: () (declarative), (Router) (programmatic). Constants: ROUTER_ATTRIBUTE, MAX_REQUEST_BODY_BYTES_PARAM.

barezen-security

Authentication, authorization, sessions, password hashing.

TypeDescription
AuthenticationFunctional interface: AuthenticationResult authenticate(Credential). Factories: anonymous(), bearer(scheme, value, principal).
AuthenticationResultSealed interface. Subtypes: Authenticated(Principal), Failure(String), Anonymous. Factories: authenticated(), failure(), anonymous().
AuthorizationFunctional interface: Decision authorize(Principal, Permission). Factories: allowAll(), denyAll(), of(Map<Principal, Set<Permission>>).
PrincipalRecord: name (String). Factory: Principal.of(String).
PermissionImmutable string identifier. Factory: Permission.of(String).
CredentialRecord: scheme (String), value (String).
SecurityContextRecord: authentication (AuthenticationResult). Methods: principal(), isAuthenticated().
SecuredHandlerWraps a handler with security. authenticated(Handler), require(Handler, Permission).
SecurityMiddlewareWires auth and authz into the pipeline. create(Authentication, Authorization).
SessionStoreIn-memory session store. standard(), create(Principal, Duration), lookup(String), invalidate(String), rotate(String, Duration).
SessionToken32-byte random token. value(), isExpired(Instant).
PasswordHasherPBKDF2-HMAC-SHA256. standard(), of(iterations, SecureRandom), hash(String), verify(String, String).

barezen-data

Database access, transactions, migrations.

TypeDescription
DatabaseEntry point. Constructor: (DataSource). Methods: query(sql, RowMapper, params), executeUpdate(sql, params), transaction(TransactionCallback).
TransactionTransaction-scoped access. Methods: query(), executeUpdate(), queryForLong().
RowMapper<T>Functional interface: T map(ResultSet, int).
MigrationInterface: version(), description(), apply(Connection).
MigratorApplies migrations. Constructor: (Database). Method: migrate(List<Migration>).
DataAccessExceptionRuntime exception wrapping SQLException.

barezen-content

Static file serving.

TypeDescription
StaticContentStatic utility. file(Path) infers content type. file(Path, String) with explicit type. contentTypeOf(String) maps extension to MIME type.

barezen-testkit

Integration testing tools.

TypeDescription
TestServerReal HTTP server on random port. start(Router), port(), baseUri(), client(), isRunning(), close().
TestHttpClientHTTP client for TestServer. Methods: get(), head(), post(), put(), patch(), delete(), options(), request(method, path).
TestResponseResponse: status(), header(String), body(), bodyBytes().
AssertionsFluent assertions. assertThat(TestResponse), assertThat(int), assertThat(Optional<Principal>).
TestDatabaseIn-memory H2 database. create(), database(), dataSource(), close().

barezen-plugins

Built-in plugins.

TypeDescription
AuthPluginAuthentication plugin. Contributes /auth routes.
UserPluginUser management plugin. Contributes /users routes.
OpenApiPluginOpenAPI documentation plugin. Contributes /openapi.json route.
