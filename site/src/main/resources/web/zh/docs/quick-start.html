快速开始

一个 handler、一张路由表、一个服务器。其余都是你按需添加的模块。

坐标

引入一次 BOM，然后只依赖你要用的东西。框架里没有任何模块依赖 barezen-security、barezen-data、barezen-content、 barezen-plugins、barezen-http-servlet 或 barezen-testkit —— 方向是单向的，这正是第二个应用可以选用另一套模块的前提。

<dependencyManagement><dependencies>
  <dependency>
    <groupId>com.barezen</groupId><artifactId>barezen-bom</artifactId>
    <version>0.1.0-SNAPSHOT</version><type>pom</type><scope>import</scope>
  </dependency>
</dependencies></dependencyManagement>

<dependencies>
  <dependency><groupId>com.barezen</groupId><artifactId>barezen-web</artifactId></dependency>
  <dependency><groupId>com.barezen</groupId><artifactId>barezen-http-jdk</artifactId></dependency>
</dependencies>

这个仓库还没有发布任何东西 —— 没有远端、没有构件、没有许可证文件 —— 所以同级项目目前只能用 mvn install 来消费它。这个"缺失"记录在 ADR-0046 里，而不是用一个看起来合理的 URL 填上。

第一条路由

Router router = Router.builder()
    .route(HttpMethod.GET, "/health", (request, params) ->
        new Response(200, Headers.of("Content-Type", "text/plain"), OK))
    .route(HttpMethod.GET, "/users/{id}", (request, params) ->
        new Response(200, Headers.of("Content-Type", "application/json"),
            ("{\"id\":\"" + params.get("id") + "\"}").getBytes(StandardCharsets.UTF_8)))
    .build();

JdkHttpServerAdapter server = new JdkHttpServerAdapter(new InetSocketAddress("127.0.0.1", 0), router);
server.start();
int port = server.port().getAsInt();
server.stop();

端口写 0 是向操作系统要一个；否则就写你部署环境拥有的那个端口。start() 每个实例只能调用一次， stop() 幂等且不抛异常 —— 一个实例就是一个服务器生命周期；让同一个对象重新开始，意味着调用方手里的引用 指向的是一个已经不存在的服务器（ADR-0024、ADR-0012、ADR-0005）。

handler 能要什么

handler 就是 Response handle(Request request, Map<String,String> parameters)。 这就是 web 层全部的扩展面，而它刻意做得很短：

  • 请求带着客户端发来的东西 —— 方法、原始路径、原始 query（不存在与为空是两回事）、每个值一行的头字段、 以及 body 字节；
  • 捕获到的路径参数作为第二个参数到达，既不是请求上的状态，也不通过 thread-local；
  • 响应带着状态码、字段和一个 byte[] body，并且拒绝 Content-Length 与 Transfer-Encoding，因为分帧属于服务器的事（ADR-0020、ADR-0027）。

一个需要知道"是谁在问"的 handler，会在 Handler 旁边再实现 SecuredHandler， 安全装饰器于是给它第三个参数。一个裸的三个参数的 lambda 不是 Handler，所以它包不起来 —— 这个形状是由检测规则拒绝的，不是靠约定（ADR-0033）。

跑示例

examples/ 模块里有七个程序 —— hello world、routing、request/response、security、database、plugin、 OpenAPI —— 每个都有一个 main()，会真的绑定一个 socket 并打印它观察到的结果， 每个也都有一份 reactor 会跑的测试。先构建，然后每个程序一条 java -cp：

mvn -o -B -ntp clean verify
java -cp "$CP" com.barezen.examples.hello.HelloWorld

完整的 classpath 写法，以及七个程序各自观察到的输出，都在 docs/examples/README.md 里。
